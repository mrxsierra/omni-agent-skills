# Getting Support for omni-agent-skills

Thank you for using `omni-agent-skills`! Here is how to find help, report issues, and discuss new ideas.

---

## 1. Where to Ask Questions

- **General Questions & Discussions:**
  If you have questions about how to integrate skills with your AI coding agents (such as Google Antigravity, Claude Code, Cursor, Codex, or OpenCode), open a discussion in [GitHub Discussions](https://github.com/mrxsierra/omni-agent-skills/discussions) or browse existing questions.
- **Documentation:**
  Check [docs/README.md](docs/README.md) for architectural concepts, project scope, decision records, and contribution procedures.

---

## 2. Reporting Bugs

If you find a bug in registry generation, validation scripts, installers, or schemas:
1. Search [existing GitHub Issues](https://github.com/mrxsierra/omni-agent-skills/issues) to see if it has already been reported.
2. If not, open a new issue using the **[Bug Report Form](.github/ISSUE_TEMPLATE/bug_report.yml)**.
3. Provide reproduction steps, expected behavior, and environment details.

---

## 3. Proposing New Skills or Features

- **New Skill Proposal:**
  Before writing code, review [docs/specifications/registry-asset-model.md](docs/specifications/registry-asset-model.md) and open an issue using the **[Skill Proposal Form](.github/ISSUE_TEMPLATE/skill_proposal.yml)**.
- **Feature or Architectural Changes:**
  For material changes to schemas or protocols, open a **[Feature Request](.github/ISSUE_TEMPLATE/feature_request.yml)** or follow the ADR/RFC process in [docs/adr/README.md](docs/adr/README.md).

---

## 4. Security Vulnerabilities

Please **do not** open public issues for security vulnerabilities or secret exposures.
Follow our [Security Policy](SECURITY.md) to report vulnerabilities privately.

---

## 5. Scope & Non-Goals

Before filing feature requests, please review [docs/foundation/scope-and-non-goals.md](docs/foundation/scope-and-non-goals.md). This repository is a portable skill registry; desktop agent orchestration runtimes, worktree managers, and delivery UIs are out of scope.
