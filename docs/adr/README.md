# Architecture decision records

ADRs preserve significant, durable choices so contributors do not need to
reconstruct them from chat history or commits.

Create an ADR for decisions involving project scope, registry schemas,
compatibility, security boundaries, installation behavior, release policy, or
other changes that would be costly to reverse.

Use sequential names such as `0002-short-decision-title.md`.

Each ADR contains:

```text
Status
Context
Decision
Alternatives considered
Consequences
Revisit conditions
```
