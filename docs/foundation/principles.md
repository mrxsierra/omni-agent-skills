# Principles

1. **Process earns trust.** Agent claims are not proof; important work should
   be supported by independently reproducible evidence.
2. **Focused assets over prompt bloat.** A registry item has one clear purpose
   and is loaded only when relevant.
3. **Tool neutrality.** Prefer portable concepts and state platform-specific
   assumptions explicitly.
4. **Human authority at meaningful gates.** Agents may assist analysis and
   execution, but maintainers retain control of security, releases, and other
   consequential decisions.
5. **Truthful claims.** Do not claim guarantees, benchmarks, compatibility, or
   automation that the repository cannot demonstrate.
6. **Documentation is part of the product.** Changes to public behavior,
   schemas, or project direction include the associated documentation.
7. **Small, reviewable change sets.** Prefer focused branches, explicit scope,
   and verification over broad untraceable changes.
