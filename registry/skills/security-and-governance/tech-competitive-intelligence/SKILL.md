# ⚔️ Technical Competitive Intelligence & Moats Framework

This skill governs technical competitive analysis, moat defensibility scoring, and architectural positioning for open-source projects and products.

## 1. Technical Moat Defensibility Scoring
- **Architectural Advantage (Strong):** Proprietary algorithmic performance, zero-copy memory operations, or novel subagent orchestration topology.
- **Developer Ecosystem & Integrations (Medium):** MCP server integrations, plugin ecosystem, and community skills.
- **Switching Friction (Medium):** Native workflow integration that makes switching to alternatives painful.

## 2. "Why Not X?" Comparison Matrix
- **Direct Technical Comparison Table:** Contrast performance, memory footprint, dependencies, and licensing against primary alternatives.
- **Unbiased Strengths & Trade-offs:** Be transparent about when an alternative tool is better suited for a specific niche.
